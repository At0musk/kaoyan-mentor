# 复试指导

用户准备复试、问复试面试/专业面试/复试英语/联系导师/调剂，或低年级用户问"为复试积累优势"（竞赛/论文/实习/科研）时使用本文档。复试形式、权重、差额比例属于高变动事实，核验规则一律按 `info-integrity.md` 执行。

## 1. 先核验复试规则，再谈准备

输出任何复试规划前，先实时核验目标院校**当年**复试录取办法，给用户一行"复试规则速览"：

| 必核验项 | 用途 |
|---|---|
| 复试形式（线上/线下）与构成（笔试/机试/面试/外语测试） | 决定准备模块 |
| 初复试权重 | 决定复试的时间投入量级 |
| 差额比例（复试人数/录取人数） | 判断擦线风险 |
| 复试科目、参考书、加试要求（同等学力/跨考） | 决定专业能力准备范围 |
| 复试线（院线/校线）与复试名单公布时间 | 决定各节点任务 |

当年办法未公布 → 按最近一年官方办法规划，标注年份并写明"待新办法公布后核对"。

## 2. 复试诊断（输出方案前先做）

按五维给用户评级（弱/一般/良好/较强），结果写入 `kaoyan-profile.md`【当前状态】区，追加一行"复试雷达"（格式同能力雷达）：

| 维度 | 看什么 |
|---|---|
| 专业能力 | 初试专业课掌握、核心课程覆盖、竞赛/项目/论文、文献阅读量 |
| 综合素质 | 简历材料完整度、经历可讲述度、表达逻辑、读研规划清晰度 |
| 英语听说 | 四六级分数、口语开口能力、听力 |
| 信息与策略 | 对该校复试形式的了解、导师方向信息、调剂预案 |
| 初试位置 | 估分/出分后相对院线的位置（安全/擦线/边缘） |

画像中已有的竞赛/科研/实习经历（`intake-profile.md` 第 2 节）是复试素材的起点。模块优先级 = 初试位置 × 该校权重。方案输出为任务表（八要素格式，见 `planning-loop.md` 第 2 节），不是"准备复试"四个字。

## 3. 专业能力考核

先按当年复试细则确认形式：专业笔试 / 机试（上机编程）/ 面试中的专业问答，三种可能并存。

- **笔试/机试**：按复试科目建知识地图与刷题计划（方法同 `subject-coaching.md` 第 4 节）；真题与回忆版按 `info-integrity.md` 的标注规则使用。
- **专业问答**四项打底：
  1. 核心课程高频概念：每个概念练到能口头讲清"定义 + 例子 + 应用"，输出标准 = 60-90 秒口头解释录音，逐个过。
  2. 初试专业课的复试延伸考点：初试考过的内容，复试常换口头形式再问。
  3. 目标方向导师近 3 年论文读 3-5 篇，至少 1-2 篇能复述"问题-方法-结论"。
  4. 毕业设计/课程设计/项目经历：每项准备 90 秒陈述（背景-我的工作-难点-结果-如果重做会怎么改），并预判 3 个追问。
- **跨考生**：加试科目按细则提前准备；本专业核心基础课（如跨考计算机 = 数据结构/操作系统/计算机网络）列为专业能力模块最高优先级。

## 4. 综合素质面试

- **材料清单逐项检查**：简历 1 页、本科成绩单、身份证/学生证、四六级与获奖证书、科研成果/作品集、政审表/体检表——以当年复试通知要求为准，缺什么补什么。
- **自我介绍**：1 分钟版 + 3 分钟版，中英文各一套。结构 = 基本信息 1 句 → 学业与初试表现 2-3 句 → 科研/项目/竞赛 2-3 句（带数据）→ 报考理由 1-2 句 → 读研规划 2-3 句。
- **高频问题逐题写提纲**（提纲，不是逐字稿）：为什么考本校本专业 / 读研规划 / 毕设细节 / 读过什么专业书和论文 / 优缺点 / 项目中最大的困难（按 STAR）/ 没考上怎么办 / 兴趣爱好。
- **追问与压力应对**：答不上 = 承认 + 给出思考路径 + 表达补课意愿；禁止不懂装懂，禁止背诵腔。
- **模拟面试 ≥ 3 轮**：每轮录音 → 自评（语速、口头禅、逻辑断层）→ 迭代；可用 AI 或同伴扮演面试官，按高频题连续追问。

## 5. 英语能力测试

先核验形式：听力笔试 / 口语对话 / 英文自我介绍+问答 / 文献朗读与翻译。

- **英文自我介绍 1 分钟版**是基本盘，练到脱稿自然说出，不是背诵。
- **高频问答 15-20 题**逐题准备要点：家乡、本科学校、专业、报考原因、读研计划、爱好、最喜欢的课程等。
- **专业英语**：整理本专业核心术语中英对照 30-50 个；朗读并口译目标方向文献摘要，每周 2-3 篇。
- **听力**：每日 15-20 分钟（四六级/新闻听力），复试前 2 周加专业场景对话。
- **每日练习量**（按剩余天数折算增减）：跟读 10 分钟 + 问答 2 题 + 术语 5 个；每周 1 次完整英文模拟并录音。
- **口语弱**：目标降级为"内容完整 + 语速稳 + 让人听懂"，不追求口音地道；备好 3 句卡壳过渡话术。

## 6. 长线优势积累（初试前的低年级规划）

主线原则：**初试分数是复试的入场券，权重最高**。长线积累是低时间成本埋线：每周投入 ≤ 总学习时长的 10%；考前 8 周冲刺期全部让位于初试。

| 年级 | 动作 | 产出标准 |
|---|---|---|
| 大一 | 绩点优先 + 四级刷高；低成本试探：进实验室见习、参加校内科技社团 | 绩点专业前 30%；四级 ≥ 500、冲 550 |
| 大二 | 选定 1-2 项深做：与目标专业对口的学科竞赛（数模/电赛/蓝桥杯/挑战杯等）或进课题组/大创；过六级 | 1 项竞赛参赛或获奖；1 段科研参与 |
| 大三上 | 竞赛冲奖窗口；确定考研目标后收尾固化产出（报告/证书/代码/数据） | 1 项省级以上奖或拿得出手的项目；能讲清自己的具体工作 |
| 大三下-暑假 | 全力初试；已有经历整理成 1 页复试素材卡（背景/角色/难点/结果/数据），每项练 90 秒口述 | 复试素材卡 1 页定稿 |
| 大四上 | 毕业设计选题向目标方向靠拢，初试结束立即投入 | 开题报告即复试材料 |

- **竞赛选择**：与目标专业相关度 > 竞赛级别 > 获奖难度。数模类适用面广，专业对口赛事优先；不为凑数参加不相关比赛。
- **论文的现实判断**：本科生独立发论文周期 3-12 个月，时间成本高。有课题组支撑的合作产出 > 挂名论文 > 自费水刊；付费版面、"给钱就发"的期刊不碰——导师普遍能识别，反成减分项。进课题组参与真实科研，价值高于挂名论文。
- **实习**：就业导向专硕加分明显（行业头部相关岗位）；学硕/科研导向 = 实验室科研经历 > 企业实习。初试当年暑假起，实习让位于初试。
- **已有经历的用法**：任何经历按 STAR 整理成可讲述版本；没获奖的参赛、没发表的科研参与都值得讲——讲清"做了什么 + 学到什么 + 数据结果"。

## 7. 时间线（初试后）

| 时点 | 任务 |
|---|---|
| 初试结束-元旦 | 估分；休整 ≤ 1 周；收集目标院校复试细则与真题；毕设开题 |
| 出分前（1-2 月） | 笔试科目第一轮；自我介绍中英文初稿；素材卡定稿；读导师论文 |
| 出分后 | 🔴 定位判断：对比院线与排名 → 全速复试 or 复试调剂两手准备；启动联系导师 |
| 国家线/院线公布 | 复试名单确认；模拟面试 ≥ 2 轮；笔试真题限时训练 |
| 复试前 1 周 | 材料终检；线上调设备场地 / 线下定行程；作息调到面试时段 |
| 复试后 24 小时 | 记录被问住的问题，调剂复试与二战复用 |

## 8. 联系导师

- **时机**：出分后。初试前联系多数无实质回复；"欢迎报考"不构成任何承诺。
- **邮件要素**：称谓 + 姓名 + 初试成绩/排名证据 + 匹配点 1-2 句（读过的导师论文、与其方向相关的项目经历，必须具体）+ 附件（简历 + 成绩单）+ 明确请求（是否还有名额）。
- **礼仪**：不同时给同院系多位导师群发；一周无回复再联系一位备选；收到"名额已满"立即转向下一位。
- **🔴 CHECKPOINT**：邮件发出前把草稿给用户过目确认——对外发送动作，不得擅自代发。
- 联系导师是信息与匹配动作，不是录取捷径；复试表现仍是主体。

## 9. 调剂预案

触发：出分后预计擦线，或复试被刷。

- 出分日起同步收集：研招网调剂系统开放时间、往年接收调剂的院校清单，按"本科背景 + 初试分数 + 专业相近度"筛 5-10 所。
- 调剂复试同样按本文件准备；调剂系统填报期规则以当年研招网公告为准。
- 调剂是信息战，提前准备者占优；既不鼓动放弃，也不美化"随便调一个"。

## 10. 失败模式与兜底

| 触发条件 | 一线修复 | 仍失败兜底 |
|---|---|---|
| 当年复试细则查不到 | 按最近一年官方办法规划，标注年份 | 给研招网 + 院校研究生院自查入口；新办法公布后重校方案 |
| 用户经历空白（无科研/竞赛/实习） | 深挖毕设/课程设计/课程项目成主打素材；用专业问答与英语提分兜底 | 禁止编造；面试用"诚实 + 学习意愿"话术应对空白 |
| 口语完全开不了口 | 从跟读 + 自我介绍 20 句起步，每日录音对比 | 问答要点熟背 + 关键词卡；面试中放慢语速、请求复述 |
| 复试被刷 | 24 小时内复盘记录；启动第 9 节调剂预案 | 用户决定二战/就业时，切回 `planning-loop.md` 或结束陪跑 |
| 联系导师无回复 | 检查邮件要素（成绩证据/匹配点/附件）后更换对象 | 不再追问同一导师；回归复试表现本体 |

## 11. 复试指导红线

1. 禁止指导或默许编造科研/竞赛/实习经历、代写申请材料——复试追问会当场戳穿，风险远大于收益
2. 禁止推荐付费版面水刊、"包过"复试班、内部关系、"打点导师"类操作
3. 禁止初试前让用户大量投入复试准备（每周 ≤ 总时长 10%，冲刺期归零）
4. 禁止凭记忆陈述当年复试形式/权重/差额比例而不核验、不标注年份
5. 禁止承诺"复试包过""导师已内定"，禁止把"欢迎报考"解读为录取承诺
6. 禁止逐字背稿式辅导——面试官对背诵腔极敏感，只做提纲与要点
