# 学习规划与复盘循环

制定学习计划、生成每日/每周任务、周月复盘、进度落后调整、执行力问题时使用本文档。

## 1. 全年阶段（按剩余时间动态计算，不机械套模板）

| 阶段 | 目标 |
|---|---|
| 阶段0 目标确定期 | 定方向、搜集招生信息、择校、制定基础计划 |
| 阶段1 基础 | 建立完整知识体系 |
| 阶段2 强化 | 从"会知识"进入"会做题" |
| 阶段3 真题 | 从"会做题"进入"会考试" |
| 阶段4 冲刺 | 提升输出速度、稳定性、应试能力 |
| 阶段5 考前 | 保持状态、降低错误率、解决高频问题 |

阶段边界由 当前时间 + 用户基础 + 目标院校 + 实际进度 决定。先算剩余时间和任务量，再排计划。

**🔴 CHECKPOINT（阶段切换）**：建议从当前阶段进入下一阶段前，向用户出示切换依据（哪些完成标准已达成、数据是什么），确认后切换并更新档案阶段字段。

## 2. 任务必须可执行

禁止空泛任务（"好好学习数学""加强专业课""多做真题"）。合格任务八要素：

| 要素 | 示例 |
|---|---|
| 时间 | 19:00–20:30 |
| 科目 | 数学 |
| 内容 | 高等数学：定积分应用 |
| 学习动作 | 看例题 + 基础题 + 错题复盘 |
| 数量 | 完成 20 道指定训练题 |
| 输出结果 | 总结 3 类题型 |
| 完成标准 | 正确率 ≥ 80% |
| 复盘 | 记录 2 个错误原因 |

## 3. 负荷管理

- 每日计划必须考虑总负荷：学习时长、专注时间、科目切换成本、疲劳、睡眠、复习周期。默认用户精力有限，不是无限。
- 高难度任务（数学综合题、英语阅读精读）放在用户精神最好的时段。
- 每天设三档完成量：**理想量**（状态好时）/ **标准量**（正常）/ **最低量**（状态差时的底线）。防止一天崩盘导致整个计划失控。

## 4. 目标分数拆解

不许只说"目标总分 400"。拆成：

```text
英语 XX + 政治 XX + 数学 XX + 专业课 XX = 总分 XX
```

并按目标院校历史数据定三档：安全目标 / 竞争目标 / 冲刺目标，随模考成绩滚动修正。

## 5. 动态调整算法

每周根据真实反馈（完成率、实际时长、正确率、错题量、记忆保持率、模考成绩、疲劳、拖延）调整：

| 状态 | 动作 |
|---|---|
| 进度超前 | 提高难度或提前进入下一阶段 |
| 正常 | 维持计划 |
| 轻度落后 | 压缩非核心任务，恢复主线 |
| 严重落后 | 重新规划任务结构（见第 7 节），不是简单加时间 |

核心原则：**优先调整计划，而不是一味增加学习时间。**

## 6. 周复盘（每周主动发起）

用户没主动汇报时，周末主动索要数据：

```text
本周计划学习 XX 小时 / 实际 XX 小时
英语：词汇完成 XX%，阅读正确率 XX%
数学：学习章节、正确率、真题成绩
政治：完成内容、选择题正确率
专业课：教材完成、背诵完成、真题
本周最大问题 / 下周可投入时间
```

收到后输出**本周复盘报告 + 下周调整计划**（哪些继续保持、哪些修正、依据什么数据），并更新档案。

复盘报告必须先做**档案对照**：从档案取三类历史数据——上周完成率、各科上次正确率/基线、目标分数三档——本周每条关键数据旁给出与档案基线的对比结论（升 / 降 / 不可直接比较及原因），不许只汇报数字不做对比。

## 7. 严重落后：做减法，不是补课

禁止"把落下的全部补回来"。任务分三类：

- **A 类 必须**：直接影响考研结果 → 优先抢救
- **B 类 重要**：可压缩
- **C 类 可选**：时间不足直接放弃

执行力下降时先诊断：任务过重？计划不现实？目标模糊？缺乏反馈？遇到具体知识障碍？然后降低门槛重建节奏（例如把最低完成量调到"只保 A 类核心 1 小时"），不要空洞喊"坚持下去"。

**🔴 CHECKPOINT（砍任务）**：把任务降级为 B/C 类或砍掉之前，先向用户列出砍什么、为什么砍、对结果的影响，确认后再改计划；用户已明确授权自动调整的除外（写进档案）。

## 8. 月度复盘（每 4 周）

输出：知识进度评估、真题能力评估、学科短板分析、学习效率分析、目标院校风险重评（必要时建议重新择校）、下一阶段任务重排。结果更新进档案。

## 9. 风险雷达（持续主动检查，不等用户问）

- **信息风险**：简章/科目/参考书/招生人数变化（盯住目标院校官网）
- **时间风险**：基础或强化落后、真题启动太晚、专业课背诵过慢
- **能力风险**：数学基础不足、英语阅读提升缓慢、政治启动过晚、专业课记忆困难
- **目标风险**：目标院校难度与当前成绩脱节、院校信息变化

发现风险立即提醒并给出处理建议。

## 10. 间隔复习

重要知识点安排复习节点：D0 → D1 → D3 → D7 → D14 → D30。单词、数学公式、政治知识点、专业课背诵分别设置合适频率，写进周计划。

## 11. 阶段计划输出结构

```markdown
# 本阶段目标（日期区间）

## 一、阶段目标（总目标 / 分科目目标 / 目标分数）
## 二、当前状态（英语 / 数学 / 政治 / 专业课，引用档案数据）
## 三、本阶段核心任务（分科目）
## 四、每日计划
| 时间 | 科目 | 内容 | 学习动作 | 完成标准 |
|---|---|---|---|---|
## 五、本周必须完成
## 六、本周测试（分科目）
## 七、复盘标准
## 八、风险提醒
## 九、下阶段触发条件
```

## 12. 择校联动

月度复盘或数据显著变化时，对照 `school-selection.md` 重新评估当前目标是否仍然合理，主动提出："根据最近四周数据，建议重新做一次择校评估。"目标不是让用户死守最初选择，而是在信息变化中持续做出合理决策。
