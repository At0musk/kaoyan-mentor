# 考研画像与长期档案

首次接触用户、收集考研画像、创建和维护 `kaoyan-profile.md` 时使用本文档。

## 1. 首次接触流程

第一次对话不要直接给学习计划——大而空的计划无法执行，还会掩盖关键信息缺失。第一次回复只包含：工作方式说明 + 画像追问 + 基于已知信息的一句话风险提示；不含任何计划表、任务安排或全书单（输出边界同 SKILL.md 会话启动协议）。按以下顺序：

1. 简短说明工作方式：
   > "我会先建立你的考研画像，再研究目标专业和院校，之后制定计划。计划会随着你的真题成绩、学习进度和招生信息变化而调整。"
2. 请用户按第 2 节模板提供信息。允许只填一部分；对直接影响规划的关键缺项（考试年份、数学基础、英语基础、目标方向）主动追问。
3. 关键缺项全部有答案后（任一未答则停在追问，不输出方案），先输出《个人考研画像 + 初步择校方向 + 风险诊断 + 当前阶段学习方案》再进入长期陪跑；其中"学习方案"仅覆盖当前阶段（未来 2-4 周）的启动安排，全年计划待画像确认后按 planning-loop 阶段结构生成。
4. 创建 `kaoyan-profile.md`（模板见第 3 节）。

## 2. 信息收集模板

```text
【考研年份】例如：2027

【本科院校】【本科专业】【目前年级】
【是否跨考】
【目标专业】
【目标城市】【目标院校】（没有可写：暂未确定）
【学硕/专硕】（没有可写：暂未确定）

【英语基础】四六级成绩、目前阅读水平
【数学基础】数学一/二/三、目前水平（哪些章节薄弱）
【政治基础】目前水平、是否已开始
【专业课】考试科目、已知的参考书

【每天可学习时长】【每周可学习天数】
【当前已开始学习的内容】
【当前最大的困难】
【最看重的因素】学校层次 / 专业实力 / 城市 / 上岸概率 / 就业 / 科研 / 学费等
```

收集时同步诊断四个维度，用户不会主动说的要追问：

- **基本情况**：本科院校/专业/年级/学历类型、是否挂科补考、四六级、竞赛/科研/实习经历。
- **考研目标**：考试年份、学硕/专硕、目标专业/城市/院校及层次、为什么考这个专业这个学校、可接受的调整范围（换校/换城市/学硕专硕互换）。
- **学习条件**：每日/每周可投入时间、上课/实习/兼职占用、作息问题、是否拖延焦虑、长期执行力。
- **各科基础**：英语（词汇量/阅读正确率/长难句/写作/是否做过真题）；数学（数几/高数线代概率基础/真题正确率/薄弱章节）；政治（基础/客观题正确率/是否开始）；专业课（科目/教材/真题/笔记/对目标院校命题风格的了解）。

## 4. 档案维护规则

- **更新时机**：周复盘后、月度复盘后、模考/真题出分、择校结论变化、阶段切换、用户基础水平重新评估后。
- **更新方式**：直接编辑对应字段，不要整文件重写丢弃历史；事件记录按时间倒序保留最近 8-12 条。
- **每次会话先读档案**恢复上下文；回答中引用档案里的具体数据（如"你上周英语阅读正确率 65%"），而不是泛泛而谈。
- 当前目录找不到档案但用户说"之前建过"，先在当前目录和上级目录搜索；确实找不到再重新收集，并告知用户新档案的存放位置。
